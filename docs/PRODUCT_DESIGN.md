# 产品设计说明

## 产品目标

Novel2Script AI 的目标是降低小说作者改编剧本的门槛。它不替代作者创作，而是帮助作者快速得到结构化、可编辑、可验证的剧本初稿。

## 用户痛点

1. 小说文本篇幅长，手动拆分场景耗时。
2. 作者熟悉叙事，但不一定熟悉剧本结构。
3. AI 直接输出纯文本剧本不便于二次编辑和程序化处理。
4. 不同平台或团队需要稳定格式，普通自然语言输出难以校验。

## 功能设计

- 小说输入：支持粘贴和上传 `.txt` / `.md`。
- 章节识别：自动识别中文和英文常见章节标题。
- 配置选择：支持剧本类型、风格、详细程度。
- mock AI 生成：模拟真实 AI 改编过程，方便无 API Key 演示。
- YAML 编辑器：输出结构化剧本，作者可直接修改。
- Schema 校验：避免 YAML 缺字段或结构不符合规范。
- 导出：支持 YAML 和 Markdown，兼顾机器处理和人类阅读。

## 交互流程

1. 用户进入首页，看到项目定位和流程。
2. 用户点击“加载示例小说”或粘贴自己的小说。
3. 系统识别章节，显示章节数量、字数、摘要。
4. 用户选择生成配置。
5. 系统生成结构化剧本 YAML。
6. 用户编辑 YAML 并重新校验。
7. 用户导出 YAML 或 Markdown。

## 创新点

- 用 YAML 作为剧本中间格式，让剧本可编辑、可校验、可导出。
- 使用 Schema 明确剧本结构，减少 AI 输出不稳定的问题。
- 将小说改编流程拆成“章节-场景-beat”，符合剧本创作习惯。
- mock AI 先行，保证比赛演示时无需真实 API Key 也能完整跑通。
