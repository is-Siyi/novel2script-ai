# 3 分钟演示指南

## 0:00 - 0:30 项目介绍

话术：

Novel2Script AI 是一个面向小说作者的 AI 剧本改编助手。它解决的问题是：小说作者想把 3 个章节以上的小说快速改成剧本初稿，但不熟悉剧本结构和格式。本工具用结构化 YAML 和 Schema 校验，让 AI 输出更可控、更容易继续编辑。

## 0:30 - 1:10 加载小说与章节识别

操作：

1. 点击“加载示例小说”。
2. 展示系统识别出的 3 个章节。
3. 指出每章有字数和摘要。

重点：

- 支持粘贴小说。
- 支持上传 `.txt` 和 `.md`。
- 支持“第一章”“第1章”“Chapter 1”等标题识别。
- 少于 3 章会提示，符合比赛要求。

## 1:10 - 1:50 配置与生成

操作：

1. 选择剧本类型：影视剧。
2. 选择风格：悬疑。
3. 选择详细程度：标准版。
4. 点击“生成结构化剧本 YAML”。

重点：

- 当前版本使用 mock AI，不依赖 API Key。
- 输出结构包含 title、logline、characters、chapters、scenes、beats。
- 每个 scene 都有 location、time、atmosphere、summary、beats。

## 1:50 - 2:30 YAML 编辑与 Schema 校验

操作：

1. 展示 YAML 编辑器。
2. 修改一处 YAML，例如删除某个 scene 的 location。
3. 点击“重新校验”，展示错误。
4. 恢复字段，展示校验通过。

重点：

- YAML 是可编辑的中间格式。
- Schema 能约束 AI 输出质量。
- dialogue beat 必须包含 character 和 content。

## 2:30 - 3:00 导出与总结

操作：

1. 点击复制 YAML。
2. 点击导出 YAML。
3. 点击导出 Markdown。

总结话术：

这个项目的核心不是简单生成一段文本，而是把小说改编成可校验、可编辑、可复用的结构化剧本初稿。后续可以接入真实大模型、长文本分段处理、角色一致性检查和更多导出格式。
